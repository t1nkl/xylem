### Improved
- **Cleaner project lists.** Projects that live in temporary folders (left behind by tools that run Claude Code once per task) no longer fill Directories, Recent Projects and Sessions. Usage still counts what they cost.
- **Clearer folder prompts.** When macOS asks whether Xylem may open your Desktop, Documents, Downloads or an external or network drive, the prompt now says why: Claude Code and the shell in your tabs need it to work with your projects there.
