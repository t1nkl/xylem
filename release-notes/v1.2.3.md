### New
- **Xylem is open source.** The code is on [GitHub](https://github.com/t1nkl/xylem) under the GNU GPL v3: you can read it, build it yourself and send fixes. The About window and Help > Open-Source Licenses show the license.

### Fixed
- Installing a skill from the skills.sh directory, and Checkout / Show Diff in the Git panel, now always pass the skill's or branch's name to the shell as plain text. Before, a specially crafted name could run a command of its own when you clicked.
