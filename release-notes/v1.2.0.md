### New
- **Intel Macs and macOS 15.** Xylem now runs on macOS 15 (Sequoia) or later, on Apple silicon and Intel Macs.
- **Select and copy in Files and Changes.** The file preview and the diff select like an editor: drag across lines, double-click a word, Cmd+A, Cmd+C. A copy is just the code, without line numbers, +/- markers or hunk headers. Cmd+F searches them.
- **Doctor fixes your PATH.** When Claude Code is installed but your shell can't find it, the Doctor shows one command for your shell (zsh, bash, fish, csh) that adds it to the right startup file. It checks again when you come back to Xylem and offers to restart the tabs where Claude couldn't start. A red Doctor opens its details by itself.

### Improved
- **Closed tabs give their memory back** and end whatever was running in them.
- **Big files in the drawer** no longer leave hundreds of MB behind after you close them.
- Folder pickers are reused instead of piling up memory.

### Fixed
- Cmd+C with a Cyrillic (or other non-Latin) layout copied and also typed "с" into Claude. Cmd shortcuts now act like on the US layout.
- A folder name with #, ? or % showed cut or changed in the window title and tab.
- New Worktree could hang forever when the repository's git hook printed a lot or left a process running.
- A git command that never finishes, or a special file in place of a project's settings, could freeze parts of Xylem.
