### New
- **Worktree button.** The strip under the terminal has a Worktree button: a new branch in its own folder, opened in a new tab (the same as Cmd+K "Git · New Worktree Tab…"). It is greyed out, with the reason in its tooltip, when the tab's folder isn't a git repository.
- **Help > Open-Source Licenses.** A window with every open-source library inside Xylem (SwiftTerm, Sparkle, the Sentry SDK), what each one does and its full license. The About window is short again: the website and the library names.
