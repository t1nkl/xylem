### New
- **Session names on tabs.** A tab is titled with the name Claude Code gives its session, or the one you set with /rename. A tab you renamed yourself keeps your name, and the window title still shows the folder.
- **Background tasks.** A tab whose Claude runs background tasks (a dev server, a long build) shows how many on its row. Closing that tab or quitting Xylem asks first, because the tasks end with it.
- **Plan and Bypass badges.** A tab in plan mode or with permissions bypassed is marked next to its title.
- **Prompt cache in the toolbar.** In the last 10 minutes before the active tab's prompt cache expires, the toolbar shows the minutes left; once it has expired, a snowflake says how many tokens the next message writes again.
- **About window.** Xylem > About Xylem shows the version, the Claude Code version, the license, the bundled libraries with their licenses and what's new in this version.

### Improved
- A session opened from Claude Code's /resume picker in another terminal is now recognised as open, so a restored tab continues it as a fork instead of writing to the same file.
- Refresh only looks up again the project folders that changed.

### Fixed
- All Sessions no longer shows "<synthetic>" as the model after a request failed.
