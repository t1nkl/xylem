### Improved
- **Bigger recent project cards.** On the New Tab screen the cards are wider with larger text, so a full screen shows fewer, easier-to-read cards and their paths fit. The icon, name and date now share the top row, which leaves room for one more row of projects.

### Fixed
- With the Claude or Git panel open on the New Tab screen, the recent project cards no longer go under the panel; the grid now drops a column instead. The same happened when the window was made narrower.
- Each project's card keeps its colour; the colours used to change on every launch.
