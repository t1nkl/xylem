### New
- **Effort in the toolbar.** Next to the model, the toolbar shows the effort level the tab's Claude runs at, as soon as it starts. Pick Low, Medium, High, Extra High or Max to change it for that session only; your default for new sessions stays as it is. Setting a level for one session needs Claude Code 2.1.257 or later (Max 2.1.76 or later); with an older version the menu greys out what it can't set and says which version it needs.

### Improved
- **The model shows at once.** The toolbar names the model a tab's Claude actually runs as soon as it starts, instead of waiting for its first reply.

### Fixed
- With the tabs above the terminal, the hidden tab sidebar no longer slides in when the pointer touches the left edge of the screen in full screen.
