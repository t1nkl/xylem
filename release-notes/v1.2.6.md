### New
- **Tabs above the terminal.** Settings > General > Show tabs: "Above the terminal" puts the tabs in a bar over the terminal, which then gets the full window width. Each tab shows the project and its latest prompt (or the permission question), the bar scrolls sideways (a mouse wheel works too), tabs reorder by dragging, and hovering a tab shows a card with the whole prompt, branch and path. The sidebar stays the default; switching keeps every session running.

### Improved
- **Much lower CPU while Claude works.** The yellow pulse around a working tab's icon used about a quarter of a CPU core per working tab (more on Intel Macs); it now uses almost none, with the same look.
- **All Sessions in three columns.** The overview fits three cards per row.

### Fixed
- Messages between agent-team teammates no longer show up as your own prompts in the Cmd-K prompt search.
