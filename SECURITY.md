# Security

Xylem runs shells in a terminal, reads your Claude Code files and updates
itself, so security problems matter. If you find one, please report it
privately through GitHub's
[private vulnerability reporting](https://github.com/t1nkl/xylem/security/advisories/new)
rather than in a public issue.

Please include the Xylem version, your macOS version and the steps to
reproduce. You'll get an answer as soon as possible, and a fix will be
released before the details are made public.

Only the latest release is supported.
