Features

Native, all the way down.

Many desktop apps are web pages in a window: a JavaScript interface running in a bundled browser or a web view. Xylem is written in Swift with SwiftUI and AppKit, and its terminal is SwiftTerm, so it looks and behaves like the rest of your Mac and stays light while Claude works.

  • 6 MBto download, 12 MB installed.
  • 0.1%of the CPU at rest, with a tab open.
  • ~100 MBof memory for the app with a tab open.
  • 0browser engines inside.

Up and running in a minute.

Xylem uses the Claude Code you already have, with your account, settings and sessions.

  1. Install Claude Code

    Skip this if claude already works in your terminal.

    curl -fsSL https://claude.ai/install.sh | sh

  2. Download Xylem

    Open the downloaded file and drag Xylem into Applications. It's signed and checked by Apple.

    Download for Mac

  3. Open a project folder

    Xylem picks up the last Claude conversation in that folder, or starts a new one. If it can't find claude, the Doctor at the bottom of the window shows how to fix it.

Questions

Is Xylem a GUI for Claude Code?

Yes, a desktop app around the real Claude Code CLI. You talk to Claude the same way as in Terminal, and Xylem adds what a terminal window lacks: several sessions in tabs, a mark on the one that is working or waiting for you, past prompts, usage and costs, your skills, MCP servers and hooks in one panel, and the project's files and git changes a click away.

Is it built with web technology, like Electron?

No. Many desktop apps run a JavaScript or TypeScript interface inside a bundled browser (Electron) or the system web view. Xylem has no web layer: the interface is Swift with Apple's SwiftUI and AppKit, and the terminal in each tab is SwiftTerm, a native terminal emulator. That is why the download is about 6 MB and the app sits at about 0.1% of the CPU while nothing happens.

Does Xylem change my Claude Code settings?

No. Xylem only reads your settings files. To know what each tab is doing, it gives claude a few extra hooks when it starts a tab (through --settings), without changing any of your files.

What leaves my Mac?

Nothing about you or your code. Xylem checks status.claude.com for outages, skills.sh for the skills directory, and once an hour this site for a new version of Xylem. If Xylem crashes, it sends a crash report to Sentry with the error, macOS version, Mac model and Xylem version, never your prompts, files or IP address. You can turn crash reports off in Settings > Updates & Privacy. Claude Code talks to Anthropic as usual.

Which Macs does it run on?

Macs with Apple silicon (M1 or newer) on macOS 26 Tahoe or later.

Does it work with nvm, mise or a custom config folder?

Yes. Tabs start claude the same way your terminal does, so nvm, mise, Homebrew and your own PATH setup all work. A custom CLAUDE_CONFIG_DIR is picked up too.

Why isn't it in the App Store?

App Store apps run in a sandbox, and a sandboxed app can't open a real terminal session. So Xylem is a direct download, signed and notarized by Apple.

How much does it cost?

Xylem is free to use. Claude Code usage is billed by Anthropic as usual, through your Claude plan or API key.

Is Xylem made by Anthropic?

No. Xylem is an independent app. Claude and Claude Code are Anthropic's products.
